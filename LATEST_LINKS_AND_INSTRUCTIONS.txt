Operational Commands
1) Check project/link status
   npx netlify status

2) Set production environment variables
   npx netlify env:set DATABASE_URL "postgresql://user:password@endpoint-pooler.region.aws.neon.tech/dbname?sslmode=require" --context production
   npx netlify env:set DIRECT_URL "postgresql://user:password@endpoint.region.aws.neon.tech/dbname?sslmode=require" --context production

3) Validate Prisma schema and migration status
   npm run db:health
   DATABASE_URL="postgresql://...-pooler..." DIRECT_URL="postgresql://...direct..." npx prisma validate
   DATABASE_URL="postgresql://...-pooler..." DIRECT_URL="postgresql://...direct..." npx prisma migrate status

4) Apply migrations and seed
   DATABASE_URL="postgresql://...-pooler..." DIRECT_URL="postgresql://...direct..." npx prisma migrate deploy
   DATABASE_URL="postgresql://...-pooler..." DIRECT_URL="postgresql://...direct..." npx prisma db seed

5) Trigger production redeploy
   npx netlify deploy --prod --trigger

6) Check latest deploy state quickly
   npx netlify api listSiteDeploys --data '{"site_id":"288b3602-09cb-4368-877f-535974603584","page":1,"per_page":3}'
